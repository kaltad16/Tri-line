# Build Tri-Line on your phone with GitHub

1. Extract this ZIP on your Android phone.
2. Open your `kaltad16/Tri-line` repository.
3. Switch to the `triline-game` branch.
4. Upload the project files/folders from this package.
5. Commit the changes.
6. Open **Actions**.
7. Open **Build Tri-Line APK**.
8. Wait for the green check.
9. Open the successful run.
10. Under **Artifacts**, download `Tri-Line-debug-apk`.
11. Extract it and install the `.apk`.

The APK is built by GitHub Actions. Android Studio is not required on your phone.
